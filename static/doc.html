FastAPI Notes Server API - Full Documentation

Note: All requests require the X-API-Key header to be set with a valid API key.

Method Endpoint Description
POST /notes Create a new note
GET /notes Retrieve all notes
GET /notes/{id} Retrieve a specific note by ID
PUT /notes/{id} Update an existing note
DELETE /notes/{id} Delete a note by ID
GET /notes/count Get total number of notes
GET /notes/by-tag/{tag} Retrieve notes filtered by tag
