Kotlin for Android: Essential Quickstart

Kotlin is the official language for Android development. It is concise, safe, and interoperable with Java.

1. The Basics

Use val for immutable (read-only) variables and var for mutable variables.

// Variable declarations val name: String = "Android" // Cannot be changed var age: Int = 10 // Can be changed // Function fun greet(name: String): String { return "Hello, $name!" }

2. Null Safety

Kotlin prevents NullPointerException. By default, types cannot be null.

var nonNull: String = "Must have value" var nullable: String? = null // '?' allows null // Safe call val length = nullable?.length // Elvis operator val lengthOrDefault = nullable?.length ?: 0

3. Android-Specific Features

Data Classes

Perfect for representing API responses or data entities.

data class User(val id: Int, val name: String) val user = User(1, "Alice")

Coroutines

Used for asynchronous programming (e.g., fetching network data without waiting on the main thread).

scope.launch { val data = fetchData() // Suspending function updateUI(data) }

Problem 1: Variables

Problem 2: Null Safety
